01

一句话结论

共享 TTD 会把 DDBS 的波束焦点打散，但打散本身无害——只要离线知道它们被打到哪（重标定查找表）。 真正失效的是平铺：焦点集合在覆盖区域里裂出空洞。

能不能补上空洞，只取决于一个量：导频梳子齿距 Δ 与子阵波束宽度 2/P 之比。 导频数量不是变量，导频分辨率才是。

R1（分辨率）  Δ ≤ 2/P     R2（跨度）  K·Δ ≥ 2
baseline 把 Δ 焊死为 2/K  ⟹  K ≥ P  ⟺  K · NTTD ≈ Nt

这条交换律是推出来的，不是拟合的；而且实测对带宽 B、对扫描参数 θt/θp 全部不敏感。 在两个独立配置上反推出的 Δmax 一致到 3%（2.06/P vs 2.00/P）。

贡献是两半，而且可分离。在 32 个 TTD（两个阶段都是）上：
  未补偿 PS + 他们的拆分，12 导频 → 0.982±0.233
  补偿 PS + 他们的拆分，12 导频 → 4.742±0.344  （补偿贡献 4.8×）
  补偿 PS + 我们的拆分，8 导频 → 6.403±0.069  （再 1.35×，导频少 1/3）
合计 6.5 倍速率、导频少三分之一，硬件两阶段完全相同。

主曲线：K 从描述里消失了

速率 vs 齿距/子阵波束宽  （仅取满足 R2 的配置）

P=8（32 个 TTD），Nt=256，SNR=15 dB。K = 4…16、三种齿距的全部配置都落在同一条曲线上。

跨 P 验证通过——这是全项目最吃重的一次验证。主曲线声称 P 和 K 只通过比值起作用， 于是特意安排了两对来自不同 P 但 P/K 完全相同的配置：
  P/K = 1.333：(P=4,K=3) → 76% vs (P=8,K=6) → 72%
  P/K = 1.143：(P=8,K=7) → 99% vs (P=16,K=14) → 101%
两对都在蒙特卡洛噪声内一致（±3 点）。主曲线不是 P=8 那次扫描的巧合——这才是「只引一条曲线而不是每个 P 一张表」的许可证。
最右侧那一簇是全表最重要的数据点。在 Δ·P/2 = 2 处，K 从 4 变到 16——导频数量翻两番——速率纹丝不动，全在 52–59%。 而 K=8 配上正确齿距是 100%，K=16 配上错误齿距只有 58%。导频数量不是变量。

已修复的统计量 bug。早先版本只在焦点之间求差，因此「密集但很窄」的焦点簇会读出极小的空洞而蒙混过关 （K=4/Δ=0.125 读 0.6 却只有 41%）。修正为先用区域边界夹住区间再求差，两个反例现在都读 128.7。 此前 25 个配置是用带 bug 的版本打分的，结论不受影响（都用 baseline 梳子），但在重跑之前不能引用「25/25」。
04

机理闭合：缺的那一项是频变栅瓣周期

此前因果链中间是空的：共享 → 残差相位 → (???) → 焦点位移 → 覆盖空洞 → 失效。 四次机理假设四次被证伪（§07）。缺的是一项——焦点图的栅瓣周期随频率变化。

θm = ⟨ umθ′p + ρθθt ⟩2um     αm = umα′p + ρααt     um = fc/fm
模数是 2um = 2fc/fm，不是 2——λc/2 阵列在 fm 处的栅瓣周期，在带内呼吸

加上这一项后，闭式复现 actual_focus 到 1.3e-4（搜索栅格本身 4.9e-4）。 消去 um，焦点轨迹成为过一个枢轴点的直线束，每个栅瓣阶次一条线；由他们的 (63)， 扫描强度 S 就是枢轴到扇区目标 θM 的距离。这是扫描速率这个旋钮的几何含义。

由此得到结论
每根导频的距离覆盖恒为 H，与 s 无关——他们 (69) 的构造保证
s 买的是什么角度遍历次数 ntr = |q|·Λ/2 ≈ (fc/fH)·S·Λ/2 ∝ s
可见栅瓣阶次（预测 vs 实测）s=1：3.5 vs 3 条（j=−2,−1,0）｜s=1/4：1.5 vs 1｜s=1/8：1.2 vs 1
覆盖律Nsec·ntr ≥ H/(2δα) = H·d·Nt²/4 = 7.99
δα = 2/(d·Nt²)（π/2 边缘相位），数值 |g|=0.9 等值线差 2.8%
扫描率形式（论文用这个）Nsec·s ≥ C，  C = H·d·Nt³·ξH²/(3.52γM) = 2.96
端到端 28/28，实测括号 (2, 3]，推出的值落在里面
B 消掉了反过来推出了 §07 那条被证伪的 K/P ∝ B/fc：Λ ∝ B 抵消了 S 里的 1/B

端到端 28/28，零拟合参数（kmin_theory.m，真实信道，L=8，4 个扫描率 × 7 个扇区数）。 Nsec·s ≤ 2 的 4 格全部不过（80.3 / 87.4 / 92.1 / 93.7%）； Nsec·s ≥ 3 的 24 格全部通过（95.5% … 100.5%）。无重叠。 C = 2.96 是在看到任何端到端速率之前推出来的。

余量必须一起报，三条。 ① 括号 (2,3] 两端差 1.5 倍，网格只把 C 定到这个精度；2.96 距最低通过格仅 1.4%， 换成数值精确的 δα（C=3.04）就误判那两格（26/28）——不能声称 π/2 判据精确。 ② 这是通过/不通过的判据，不是速率模型：等 Nsec·s 处速率仍差 3 点（s=1/4 读 99.9%，s=1 读 97.2%），别在这些点上拟合曲线。 ③ 格点量化形式（Nsec·ntr）反而更差：25/28，阈值保守 1.7 倍。 ntr/s = 2.55 / 2.42 / 2.17 / 1.58，s=1/8 处 38% 的量化亏空正是误判发生的地方。 论文用光滑的 Nsec·s 形式。
一处归因错误已更正。覆盖约束绑在 Nsec 上而不是 K。 早先版本把它记成 K·s ≥ 4（C 是拟合的），因为 hw_budget.m 固定 Nsec=8 扫 Kα，两者是同一根轴—— 正是 §07 末尾那条方法论教训的重演，而规矩是我们自己写的。原结论（s=1/8 时 K=32 是下界、花 TTD 换不回来）不变，理由现在说对了。
Kα 是另一种基元，顺带解释了重标定为什么必需。 插值把 αt 偏移 0.087，第二根导频的设计 α 轨迹落到 [−0.0844, 0.0130]—— 87% 的扫描在可实现范围以外。重标定查表把 40% 的子载波钉在 αmin 上，横跨该导频 0.395 角度片中的 0.262， 于是它变成一次 αmin 上的平角度扫描——直线束产生不了的覆盖基元。
而它完全依赖重标定：s=1/8、Kα=2 时，有重标定 0.935，用标称查表只有 0.456。 §01 说重标定"必需"过去只有 85%-焦点位移这个观测，现在有机制了。
但效率排序被端到端推翻了。那个"扇区要 K≈42"来自离线代理量，真实答案是 24。改用实测：
  s=1/4：扇区 K=12（95.5%）vs 插值 K=16（98.0%）
  s=1/8：扇区 K=24（97.5%）vs 插值 K=32（97.6%）
扇区反而便宜约 1.3×。机制结论不变（Kα 确实是另一种基元），被推翻的是建在它上面的效率排序—— 而这加强了贡献 B：「导频投到角度维而非距离维」以前只在 s=1 处成立，现在四个扫描率全成立。

三个研究问题的答案

问题结论
① 原架构/算法在有限 TTD 下还能用吗 不能 32 个 TTD、原参数 → 理想速率的 42–43%；64 个 → 74%。
② 设计新方案逼近理想 能，且代价已精确刻画 两条杠杆：(i) 重标定查找表——免费、纯算法，而且必需（85% 的焦点偏移超过一个栅距）；(ii) 导频梳子 Δ ≤ 2/P，即 K ≈ P。
③ 抛弃 DD-BS 换新架构 按原提法关闭 θt 偏置是承重的（单独缩小它反而更差，12%）；共享极限是子阵波束宽性质，不是参数选择。

G · 速率 vs SNR  L=8，32 个 TTD（两阶段）

四条线把两笔账分开：MRT−oracle 的差 = 分组的代价（全程 0.3–0.7%，几乎为零）； oracle−ours 的差 = 训练的代价。导频数不同（8 vs 12），这是「各自最好配置」，不是等开销。

必须写进论文的局限：SNR 低于约 10 dB 时本文方法也塌——0 dB 只有 9%，5 dB 只有 23%。 判决是在 M=1024 个子载波上取 argmax，所以门限由选择问题决定，不是由阵列增益决定： 低 SNR 下 1024 个含噪样本的最大值就是噪声。
这同时修正了「估计器方向已关闭」那个结论。 oracle/coarse = 1.02× 是在 20 dB 测的；0 dB 处同一个比值是 11×。 所以那个界必须带着 SNR 一起引用，低 SNR 角落是敞开的——而且被 OJ-COMS 自己的 MF 精化占着（他们的 Fig 10）。

§04 把判定 #3 的第二行往回收了一点，这是唯一一处。 他们的 (29)–(31) 是标称焦点闭式，缺两项，而且两项都是承重的：

② 不可实现 α 的钳位——Kα 插值导频有 87% 的扫描落在 α 范围以外，钳到 αmin 后才成为一次平角度扫描。
去掉钳位、直接用标称查表，s=1/8、Kα=2 从 0.935 掉到 0.456。 所以网格重标定不是他们闭式的冗余复制，差别可以量化，并且要在论文里量化。

还剩下什么：一处架构差异。他们的相移器 (14) 只写入 kc(n·d·θ′p − n²d²α′p)；本项目的 shared 臂在 同一套硬件上额外写入精确的 2πfcτn—— 不多一个器件、不多一位分辨率，只是给一个已经存在的相移器写了不同的值。 组内残差于是从 2πfm(τg−τn) 变成 2π(fm−fc)(τg−τn)。 代入他们自己的 (46)：πξm → π(ξm−1)， 在 B/fc=1/6 处 1.083 → 0.083，约 13 倍，经 (52)–(54) 即扇区宽 13 倍、扇区偏移数 1/13。

那一步已经走完，结论是「窄但站得住」。 他们的完整方案已按原文实现（ojcoms_algorithm1.m：(29)–(31)、(53)–(54)、(62)–(64)、(69)–(71)， L=2 直接用 Table 3 原文），在其工作点复现了 Fig 8 全部五点。 在同 (NTTD, Ktotal) 下加上 fc 补偿：L=8、32 TTD 处 12 导频 0.982 → 4.742（4.8×）， 再改拆分后 8 导频 6.403（98%）——Ktotal 从 12 降到 8 且速率提升。 唯一的保留：距离交织方式原文未规定，是我们的解释（§04 表明它靠 α 钳位工作），不能把由此产生的现象算到他们头上。
